# Ferrite 0.4: статус миграции

Новый runtime полностью написан на Rust; legacy-код оставлен для сравнения. Это ещё не полная функциональная эквивалентность всем правилам 1401/OpCore-Simplify.

| Подсистема | Перенесено | Осталось |
|---|---|---|
| GUI | Нативный интерфейс, фоновые операции, прогресс, выбор параметров, мастер EFI/Recovery/USB | Windows UI QA, доступность, сохранение настроек |
| Аппаратные данные | Импорт JSON; Linux proc/sysfs; Windows SetupAPI/CPUID/SMBIOS/firmware | Реальные Windows проверки, полная topology/MUX/panel, сравнение всех моделей |
| Правила | Основные диапазоны CPU/GPU/storage и периферии, каталог kexts, зависимости/конфликты, модели/кодеки | Полная дифференциальная проверка всех исключений upstream |
| EFI | Закреплённые архивы, SHA-256, config, SMBIOS, kext plugins, драйверы, AMD patches, обязательный ocvalidate | Некоторые iGPU/SMBIOS/новейшие OS случаи и NVIDIA companion |
| ACPI | Проверка таблиц, namespace, iasl, EC/USBX/PLUG/ограниченный AWAC | Персональные PNLF/battery/IRQ/I2C/RTC и USB mapping |
| Recovery | Нативный Apple protocol, RSA chunklist, каждый блок, resume | Длительные сетевые и все OS regression checks |
| USB | Новый FAT32/MBR образ, хеши после записи, Linux/Windows locking/identity, elevation CLI | Физическая флешка на обеих ОС; Linux/Windows installation QA |
| Поставка | Cargo workspace и Windows/Linux CI artifacts | Подписанные установщики, обновления, стабильный релиз |

## Архитектура

ferrite-core выполняет операции; ferrite-cli использует то же ядро и служит отдельным привилегированным writer. ferrite-desktop остаётся непривилегированным. Сборка создаётся в новой папке, привязана к SHA-256 отчёта и сопровождается BIOS.txt/build-result.json. Writer повторно проверяет EFI с валидатором из закреплённого пакета, подписанный Recovery и идентичность диска; сериализованному ready не доверяет.

Источники данных: OpCore-Simplify e5d8a9f551b1e2a96e2f968696b460b65a7dad2e; Hardware Sniffer 6570f91c33c63f5bf481db31789f903b0d12099f. upstream/PINNED.json и bundled manifests задают воспроизводимые версии. Компоненты latest автоматически не скачиваются.

Analysis.ok означает диапазон обязательных устройств; ready/ocvalidate означает структурно корректную EFI. Ни один результат не гарантирует загрузку macOS на конкретном ПК. Физический USB writer ещё требует проверки на настоящем железе.

## Локализация 0.3

Три JSON-каталога с одинаковыми ключами и параметрами; русский, английский и испанский. Переключение без перезапуска, сохранение языка, отдельная страница гайда и локализованный экспорт GUI/CLI. Техническая диагностика и данные импортированного отчёта сохраняют исходный текст; они отделены от переведённого рабочего процесса. Источники, версии компонентов и лицензии остаются в документации, а не в основных действиях интерфейса.

## macOS и дизайн 0.4

Редакторная компоновка, вкладки/палитра команд, read-only macOS scan/disk inventory, импорты чужих отчётов, системные пути, macOS утилиты сборки EFI и упаковщик .app/DMG. CI добавляет macos-15 (ARM) и macos-15-intel. В Linux Apple-target check остановился из-за отсутствия SDK; никакой успешный запуск на Mac не заявляется. Прямая запись физических USB на Mac запрещена capability gate; файл образа поддерживается.
