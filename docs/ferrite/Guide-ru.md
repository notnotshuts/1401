# Ferrite — Установка шаг за шагом

Пройдите шаги по порядку. Настройки BIOS могут называться иначе на вашем ПК.

## 1. Проверьте оборудование

Просканируйте ПК или импортируйте Report.json. Выберите macOS и проверьте ограничения графики, сети и накопителей. Для сборки нужна папка ACPI с DSDT этого же ПК.

## 2. Подготовьте BIOS

Сохраните текущие настройки BIOS. Если Windows использует BitLocker, сохраните ключ восстановления до изменений. Не меняйте RAID/VMD/AHCI без подготовки установленной ОС.

Отмечайте только настройки, которые уже проверили в BIOS. Эти отметки не меняют BIOS.

- [ ] UEFI включён; CSM/Legacy выключен
- [ ] Secure Boot выключен для загрузки OpenCore
- [ ] Fast Boot выключен
- [ ] Режим накопителей проверен: AHCI, VMD при необходимости выключен
- [ ] XHCI Hand-off включён, если есть
- [ ] Above 4G Decoding включён, если есть
- [ ] Re-Size BAR проверен для выбранной графики
- [ ] Intel: CFG Lock, VT-d и DVMT сверены с конфигурацией; для iGPU обычно нужно не менее 64 MiB DVMT

## 3. Соберите EFI

Откройте OpenCore EFI, выберите macOS и папку ACPI. Нажмите «Собрать и проверить EFI». Продолжайте после успешной проверки. Для сложных ноутбуков могут понадобиться персональные ACPI-патчи.

## 4. Скачайте Apple Recovery

После сборки нажмите «Далее: скачать Apple Recovery». Нужен интернет. Дождитесь завершения загрузки и проверки образа.

## 5. Подготовьте USB

Подключите USB на 8–128 GiB и обновите список накопителей. Сверьте модель, размер и серийный номер. Сохраните нужные файлы: запись удалит все данные на выбранном USB. Введите точный путь и запустите запись. Либо создайте файл образа без изменения дисков.

На macOS выбирайте целый USB-диск, например `/dev/disk4`, а не раздел `/dev/disk4s1`. Подтвердите системный запрос прав администратора; окно Ferrite остаётся без повышенных прав. Если том занят, закройте окна Finder и терминалы внутри флешки. После успешной записи накопитель извлекается автоматически — подключите его снова, чтобы открыть EFI. На Apple Silicon импортируйте отчёт и ACPI целевого Intel/AMD ПК.

## 6. Загрузитесь и проверьте результат

Откройте UEFI Boot Menu и выберите USB. В OpenCore выберите Recovery; установка macOS использует интернет. Перед форматированием проверьте целевой диск. После установки проверьте сеть, звук, USB, экраны и сон. Держите установочный USB до проверки загрузки с внутреннего диска.

## Если что-то не получилось

Ошибка сборки: проверьте папку ACPI и путь к iasl. Нет накопителя: обновите список и откройте причину блокировки. Ошибка загрузки: проверьте интернет и повторите операцию. EFI не загружается: сверяйте BIOS и оборудование; включите подробный журнал в дополнительных настройках. Подробности ошибок доступны в журнале.
