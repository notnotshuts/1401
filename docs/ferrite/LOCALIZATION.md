# Локализация Ferrite 0.3

Каталоги: `crates/ferrite-core/locales/{ru,en,es}.json`. Формат — один JSON-объект: стабильный ключ → строка UTF-8. Группы: nav, action, settings, hardware, build, usb, guide. Для добавления текста внесите одинаковый ключ во все три файла. Параметры `{0}`, `{1}` и именованные параметры должны совпадать между языками; их порядок можно менять. Значения подставляются один раз, поэтому фигурные скобки в путях не интерпретируются как параметры.

UI использует `tr(key)` и `tf(key, params)`. Отсутствующий перевод получает английское значение; отсутствующий во всех каталогах ключ отображается как ключ. Нормальная поставка проверяет полноту каталогов тестами. Исходный текст диагностических инструментов доступен в раскрывающихся блоках с пояснением; названия устройств, пути, PCI ID, журнал прошлых операций и JSON-данные не переводятся.

Выбор языка хранится в preferences.json: macOS — ~/Library/Application Support/Ferrite; Windows — APPDATA/ferrite; Linux — XDG_CONFIG_HOME/ferrite или ~/.config/ferrite. Запись атомарная. При первом запуске учитываются LC_ALL/LC_MESSAGES/LANG; неподдерживаемая локаль использует русский. На Windows без этих переменных язык выбирается вручную. Наличие FERRITE_PREVIEW_LANGUAGE влияет только на сборку с feature screenshot.

Проверки: одинаковые ключи и параметры всех языков, переключение языка, региональные локали, безопасная подстановка значений, рендер гайда на трёх языках, сохранение/замена preferences. Нативные снимки overview/guide сделаны для ru/en/es.
